# Notice — Color Utilities

K3UI utilise `@material/material-color-utilities` (Apache-2.0, Copyright Google LLC)
comme dépendance runtime pour les algorithmes HCT / Dynamic Scheme.

La façade publique reste dans `src/utils/color/` (wrappers K3UI, tokens d'état,
extensions warning/success/info, conversions ColorPicker).
