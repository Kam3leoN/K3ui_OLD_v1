# Changelog

Tous les changements notables du projet sont documentés dans ce fichier.

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/), et le projet adhère à [Semantic Versioning](https://semver.org/lang/fr/) dans la mesure du possible.

## [Unreleased]

### Changed

- **Extensions layer** : QrCode, BarCode, Signature, Firework, Confetti, Snow, Halo, Holo, Gradient déplacés sous `src/extensions/` (generators / effects) ; API publique `K.*` et AutoInit inchangés ; shims `src/components/*` conservés temporairement pour imports profonds.
- Nouveau manager **Gesture** (`GestureManager`, Pointer Events) et extension **SwipeDeck** (pile swipable).
- API `K.loadExtensions()` + namespace `K.Extensions` (alias de découverte ; `K.QrCode === K.Extensions.QrCode` après chargement).
- Docs : catégorie **Extensions**, page `swipe-deck.php`, voir `docs/EXTENSIONS.md`.

### Changed

- **Menu** : icônes leading depuis `items` JS en `size="md"` (comme le markup thème) ; CSS menu force aussi `min/max-width/height` à `$menu-icon-size` (20px) pour éviter le débordement des tailles IconManager.
- **Autocomplete** : le panneau de suggestions utilise désormais le composant **Menu** M3 Expressive (`k3ui-menu` / `menu-item`, Floating UI, états actifs) au lieu d’un listbox custom ; `Menu.autoFocus` est respecté (`false` pour garder le focus sur l’input).
- **Menu** : options `triggerToggle` et `restoreFocus` pour les hôtes (Select / Autocomplete) — évite la fermeture immédiate au clic après `openOnFocus`.
- **Autocomplete** : plus de réouverture intempestive après fermeture (`focus` programmatique ne relance plus `openOnFocus` ; pas de refocus après clic extérieur).
- **Breaking** : le composant **RadioCard** est remplacé par **Toogle** (`K.Toogle`, classes `toogle-item`, `toogle-input`, `toogle-tile-group`, etc.). Fichiers SCSS `radio-card.*` remplacés par `toogle.*`. Doc : `k3ui-docs/toogle.php` (anciennes URLs `radio-card.php` redirigent vers `toogle.php`). Tests : `Toogle.test.ts`.
